# Module 6: Text Setup - Typographic Branding & Info

The Text Setup module provides a deterministic way to add pricing, sizing, or marketing copy to generated assets without risking the "AI hallucination" of garbled text.

---

## 1. Overview: Pixel-Perfect Typography
Similar to the Logo Module, the Text Setup module operates as a **Post-Processing Layer**. 
- **The Problem:** AI image models (like Gemini) struggle with consistent rendering of specific text strings, often resulting in typos or unreadable glyphs.
- **The Solution:** Studio.AI renders the image first, then uses the **HTML5 Canvas API** to "stamp" the exact user-defined string on top. This ensures 100% legibility and brand compliance.

---

## 2. The Typographic Logic (The "How")
The `applyTextOverlay` function in `geminiService.ts` executes the following logic:

1.  **Metric Calculation:** The font size is calculated relative to the image height (e.g., a "5% scale" on a 1536px image results in a 76px font height).
2.  **Shadow & Contrast:** A soft text shadow (offset 2px, blur 4px) is automatically applied to ensure readability regardless of the background color generated by the AI.
3.  **Coordinate Mapping:** The module maps 7 anchor points (Top L/C/R, Bottom L/C/R, and Center) to precise pixel coordinates on the generated canvas.
4.  **Flattening:** The text is rendered as part of the `toDataURL` export, creating a single flattened JPEG that looks like a professionally designed ad.

---

## 3. Input Types & Presets

| Component | Type | Technical Value |
| :--- | :--- | :--- |
| **Text Content** | User Input | The raw string (e.g., "S, M, L, XL" or "NOW $29.99"). |
| **Placement** | Content Preset | 7 Anchor Points (Includes Center and Top/Bottom Centers). |
| **Scale (Size)** | User Input | 1% to 20% relative to image height. |
| **Color** | User Input | Hex Code (Converted to `ctx.fillStyle`). |
| **Transparency** | User Input | 10% to 100% alpha blending. |

---

## 4. Fixed Logic vs. User Input

| Category | Item | Description |
| :--- | :--- | :--- |
| **Fixed Logic** | `applyTextOverlay` | The deterministic rendering engine that guarantees text legibility. |
| **Fixed Logic** | Dynamic Baseline | Logic that adjusts the vertical anchor point based on whether the text is at the Top or Bottom. |
| **User Input** | Marketing Copy | The specific message the user wants to convey. |
| **User Input** | Stylization | The specific font size, color, and opacity chosen in the UI. |

---

## 5. Integration: The "Final Assembly"
The Text Module is the last step in the production line:
1.  **AI Engine:** Generates the raw scene.
2.  **Dimension Module:** Crops the canvas.
3.  **Logo Module:** Adds the brand mark.
4.  **Text Module:** Injects the final message/sizing info.
5.  **Output:** A polished, "Ready-to-Post" marketing asset.

---

## 6. Layout Strategy
To avoid "crowding" the product, the Text Setup module uses a **Safe Zone Logic**:
- Text is always pushed away from the absolute edge by a 5% padding margin.
- Alignment logic (`ctx.textAlign`) automatically switches based on the chosen preset (e.g., "Top Right" automatically right-aligns the text string).
